# Project Brief: Scenaria

## Core Mission

Scenaria is a tool and language designed to facilitate collaborative design discussions. It allows users to describe a system's high-level structure and various scenarios within that system. These scenarios can then be visually played out and easily shared among team members.

## Key Goals

- **Expressive and Simple:** Provide an intuitive syntax for describing systems and interaction scenarios.
- **Immediate Visualization:** Allow users to instantly see their models and any changes they make represented visually.
- **Effortless Collaboration:** Enable sharing of system designs and scenarios through a simple, shareable link.
- **Zero-Setup Deployment:** Function as a purely client-side, browser-based application that requires no server or database setup.
