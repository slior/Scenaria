# Product Context

## Problem Space

- Design discussions can be hard to follow and align on without a shared, dynamic visual representation.
- It is difficult to communicate complex system interactions and scenarios using static diagrams or just text.
- Collaborating on system design often requires heavy, complex tools, hindering rapid iteration.

## Target Audience

- **Developers, Architects, and Designers:** Professionals involved in the technical design and discussion of software systems.
- **Teams:** Groups that need a common ground to visualize and iterate on system behavior.

## User Experience Goals

- **Expressive & Easy:** A simple and intuitive language for describing system structure and behavior.
- **Immediate Feedback:** Instantly see changes to the model reflected in the diagram and scenario player.
- **Seamless Sharing:** Allow users to share a complete system model and scenarios with a single link.
