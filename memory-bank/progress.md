# Progress

## What Works

The Scenaria application is functional. Key working features include:
- **Language Parsing:** The custom language for defining models and scenarios is parsed correctly.
- **Diagram Rendering:** The system model is rendered visually as an SVG diagram.
- **Auto-Layout:** The diagram layout is calculated automatically by `elk.js`.
- **Scenario Execution:** Scenarios can be selected and executed step-by-step, with visual feedback on the diagram.
- **State Sharing:** The entire model and scenario set can be shared via a URL.
- **In-browser Editor:** A full-featured editor is available for writing the Scenaria code.
- **Docker Deployment:** The application can be built and deployed as a Docker container.

## What's Left to Build

The core functionality is in place. Future work will depend on user feedback and project goals, but could include:
- New language features (e.g., different node shapes, more complex interactions).
- UI/UX improvements to the editor or control panel.
- Performance optimizations for very large diagrams.
- Exporting diagrams to different formats (e.g., SVG, PNG).
